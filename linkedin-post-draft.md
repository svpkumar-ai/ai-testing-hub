## Option 1 — Storytelling Style (Recommended)

Tired of spending 2 hours every week just to stay updated on AI testing trends?

That was me. Switching between 10+ YouTube channels, bookmarking blogs, losing links — it was a full-time job *before* the actual job.

So I built something to fix it: **AI Testing Hub** 🚀

A curated, real-time news aggregator for QA professionals and software testers — pulling the best content from the top testing channels and blogs, all in one place.

---

**The Problem:**
QA engineers and test automation professionals are in the middle of one of the fastest-moving shifts in software — AI is rewriting how we test. But discovering that content is fragmented across YouTube, LinkedIn, Substack, and 10 different blogs.

There was no single home for the QA community to stay current.

---

**What I Built:**

🔍 **Aggregates 12+ top YouTube channels** — ExecuteAutomation, Rahul Shetty Academy, Naveen Automation Labs, AI with Brandon, and more

📰 **Pulls from leading QA blogs** — Applitools, BrowserStack, Software Testing Help, Katalon

🤖 **AI-relevance detection** — auto-tags content covering LLMs, GPT, Copilot, AI Agents, Playwright, Selenium, Cypress, and more

⭐ **Top Viewed rankings** — surfaces the most-watched, highest-engaged content first

🔖 **Personal saved library** — register to bookmark articles and revisit them anytime

📱 **Responsive UI** — sidebar filters on desktop, chip navigation on mobile

---

**Who is this for?**

✅ QA Engineers & SDETs staying current on AI testing tools
✅ Test Automation Engineers learning frameworks like Playwright, Cypress, Selenium
✅ Engineering Managers tracking the AI-in-testing landscape
✅ Students breaking into automation & AI testing
✅ Anyone who's tired of missing great content because the internet is too loud

---

**The Stack:**
→ React 19 + TypeScript + TailwindCSS v4
→ Express 5 + PostgreSQL (Neon serverless)
→ Drizzle ORM + Zod for type-safe APIs
→ YouTube Data API v3 + RSS fallback
→ JWT auth + bcryptjs
→ OpenAPI-first with generated React Query hooks
→ Deployed on Vercel · Monorepo via pnpm workspaces
